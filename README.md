# Claude Skills by AI With Elias

Free, ready-to-use skills for [Claude Code](https://claude.com/claude-code). Each folder is one skill. Every skill starts with zero context: it interviews you first, then does the work for you.

## Skills

| Skill | What it does |
|---|---|
| [**Reel Studio**](reel-studio/) | Turns your script and raw, uncut talking-head footage into a finished, edited reel (Instagram, TikTok, Shorts) in your own style. |

## How to install a skill

1. Click **Code → Download ZIP** at the top of this page and unzip it (or `git clone https://github.com/limitless-creator/claude-skills`).
2. Copy the skill's folder (for example `reel-studio`) into your Claude skills folder:
   - Mac/Linux: `~/.claude/skills/`
   - Windows: `%USERPROFILE%\.claude\skills\`
3. Start a new Claude Code session and type `/` plus the skill's name (for example `/reel-studio`).

Each skill's own page explains what you need and what it costs.
